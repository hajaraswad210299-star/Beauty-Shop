# VELVETY — Beauty &amp; Wellness

Faithful, responsive web build of the **VELVETY – Beauty &amp; Wellness UI Kit** (Figma), hand-coded in vanilla HTML/CSS/JS with full-bleed sections, scroll animations and micro-interactions.

## Pages
- `index.html` — Home
- `about.html` — About Us
- `shop.html` — Shop

## Fonts
- **IvyMode** (headings) — `assets/fonts/ivy-mode/`
- **Aileron** (body) — `assets/fonts/aileron/`

## Run locally
Any static server, e.g.:
```bash
python -m http.server 5500
```
Then open http://localhost:5500

## Deploy
Static site — no build step. On Vercel use framework preset **Other**, output directory **root**.
